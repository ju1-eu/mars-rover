# Cornell-Notizen: Elektromagnetische Induktion

| **Fragen / Schlüsselbegriffe**             | **Notizen & Details**                                                                                                                                                                                                                                                                                                                                                                                                |
| :----------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Was ist elektromagnetische Induktion?**  | • **Definition:** Die Entstehung einer elektrischen Spannung in einem Leiter durch die Änderung eines Magnetfeldes. <br>• **Entdecker:** Michael Faraday (1831).<br>• **Kernprinzip:** Magnetismus kann Elektrizität erzeugen (und umgekehrt).                                                                                                                                                             |
| **Wie funktioniert es? (Ursache–Wirkung)** | Es gibt zwei Hauptwege, um Induktion zu erzeugen:<br>1. **Bewegung des Leiters:** Ein Leiter (z. B. ein Draht) wird durch ein stehendes Magnetfeld bewegt. Die Lorentzkraft trennt die Ladungen im Draht → Spannung entsteht.<br>2. **Änderung des Magnetfeldes:** Ein Magnetfeld um einen ruhenden Leiter ändert seine Stärke (z. B. Magnet wird hinein/ hinaus bewegt oder Elektromagnet wird ein/aus geschaltet). |
| **Das Induktionsgesetz**                   | • Die induzierte Spannung $U_\text{ind}$ ist umso größer, je:<br>• **schneller** sich das Magnetfeld ändert.<br>• **stärker** das Magnetfeld ist.<br>• **öfter** der Draht gewickelt ist (Anzahl der Windungen einer Spule).                                                                                                                                                                                         |
| **Lenzsche Regel**                         | • **Aussage:** Der induzierte Strom wirkt immer seiner Ursache entgegen.<br>• **Beispiel:** Nähert man einen Magneten einer Spule, entsteht ein Strom, der ein Magnetfeld erzeugt, das den Magneten abstößt (Energieerhaltungssatz).                                                                                                                                                                                 |
| **Anwendung: Elektromotor (Galaxy RVR)**   | • **Umkehrprinzip:** Beim Motor nutzen wir Strom, um ein Magnetfeld zu erzeugen (in den Spulen des Rotors).<br>• **Interaktion:** Dieses Magnetfeld stößt sich von den Dauermagneten im Gehäuse ab.<br>• **Folge:** Die Achse dreht sich → elektrische Energie wird in mechanische Energie (Bewegung) umgewandelt.                                                                                          |
| **Weitere Beispiele**                      | • Generatoren (Fahrraddynamo).<br>• Transformatoren (Netzteile).<br>• Induktionsherde.                                                                                                                                                                                                                                                                                                                               |

---

### Zusammenfassung

Elektromagnetische Induktion ist der Prozess, bei dem durch **Bewegung** oder **Änderung eines Magnetfeldes** eine elektrische **Spannung** erzeugt wird. Im Kontext deines Roboters ist dies das physikalische Fundament: Strom erzeugt Magnetfelder, die gegen feste Magnete drücken und so die Räder drehen lassen. Ohne Induktion gäbe es keine Elektromotoren.
