Detailed Description

Implementierung der Antriebslogik (Kinematik-Layer).

Übersetzt High-Level Fahrbefehle (Vorwärts, Drehen) in spezifische Motoransteuerungen für einen Differenzialantrieb (Differential Drive). Dient als Abstraktionsschicht zwischen Applikation und HAL.
